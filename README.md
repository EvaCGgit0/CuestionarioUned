## 📊 Estructura del Cuestionario

### Sección 1: Datos Personales (P0-P5)
- Centro Asociado UNED
- Identidad de género
- Experiencia como tutor/a
- Nivel de estudios
- Formación previa en diario reflexivo
- Facultad/Escuela

### Sección 2: Cómo Acompañas (P6-P10)
- **IDX_SOSTEN**: Índice de sostenimiento emocional (P6+P7)/2
- **IDX_TECNICO**: Índice de mediación técnica (P8+P9)/2
- **Validación**: Estilo tutorial con metáforas visuales (P10)

### Sección 3: Herramientas y Competencias (P11-P15)
- Uso del diario reflexivo (P11)
- **Escenario situacional**: Mediación reflexiva (P12)
- Adaptación de estrategias (P13)
- **Competencia digital**: Escala visual con colores (P14)
- **Necesidades formativas**: Texto libre (P15)

### Sección 4: Participación Futura (P16)
- Interés en investigación posterior
